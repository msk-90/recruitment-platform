# Recruitment & Talent Management Platform

A SaaS-style recruitment platform where recruiters post jobs, candidates apply,
and recruiters manage the hiring pipeline end-to-end.

## Tech Stack
- **Frontend:** React + Tailwind CSS
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **Auth:** JWT

## Features
- Role-based auth (Recruiter / Candidate)
- Job posting & management
- Application system
- Candidate pipeline (Applied → Shortlisted → Interview → Hired/Rejected)
- Dashboard with analytics
- Profile management
